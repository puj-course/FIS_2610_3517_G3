Sprint 10 – Avance del Desarrollo

# 1. Objetivo del Sprint

El objetivo del Sprint 10 fue avanzar en el desarrollo de funcionalidades relacionadas con la gestión de usuarios y la ejecución de rutinas dentro del sistema NoraFit. En particular, se trabajó en la integración entre la interfaz de usuario y la lógica del sistema para permitir la visualización y ejecución de rutinas HIIT, además de continuar con la documentación técnica del proyecto.

Este sprint también incluyó la implementación de componentes de interfaz, la conexión con la lógica del dominio y la aplicación de patrones de diseño para estructurar el comportamiento de los ejercicios.

---

# 2. Funcionalidades Trabajadas

Durante el Sprint 10 se desarrollaron o avanzaron las siguientes funcionalidades:

- Registro del nombre del usuario dentro del sistema.
- Visualización de rutinas disponibles para el usuario.
- Obtención de rutinas desde el backend.
- Mostrar las rutinas disponibles en la interfaz de la aplicación.
- Implementación de la lógica de ejercicios tipo HIIT.
- Implementación de jerarquía de clases para ejercicios de cardio.
- Ejecución de ejercicios HIIT utilizando el patrón Observer.
- Integración del ejercicio HIIT dentro de la aplicación.

Estas funcionalidades permiten mejorar la interacción del usuario con el sistema y avanzar en el módulo principal de entrenamiento del proyecto NoraFit.

# 4. Cambios Realizados en el Sistema

## 4.1 Cambios en el Frontend

Durante este sprint se realizaron modificaciones en la interfaz del sistema para permitir la interacción con las nuevas funcionalidades implementadas.

Principales cambios:

- Creación de un campo para registrar el nombre del usuario.
- Implementación de componentes para visualizar rutinas disponibles.
- Conexión de la interfaz con los servicios del sistema.
- Mejora en la presentación de las rutinas dentro de la aplicación.

Tecnologías utilizadas:

- Java  
- Java Swing  

---

## 4.2 Cambios en el Backend

En el backend se trabajó en la lógica que permite manejar rutinas y ejercicios dentro del sistema.

Cambios principales:

- Implementación de la lógica de ejercicios HIIT.
- Implementación de una jerarquía de clases para ejercicios de cardio.
- Aplicación del patrón de diseño **Observer** para la ejecución de ejercicios.
- Desarrollo de métodos para obtener rutinas disponibles.
- Integración con la interfaz para mostrar información al usuario.

Tecnologías utilizadas:

- Java  
- Programación orientada a objetos  
- Patrones de diseño
